Overview

FocusForge was built to solve a problem most college students run into: juggling assignments, study goals and deadlines across too many scattered notes and apps.

The platform brings task tracking, a focus timer and a study dashboard together in a single, distraction-free interface, so students can see what's due and get straight into a focused session.

Key Features

  • Task & deadline tracker — add assignments and coursework with due dates, and see what's coming up next at a glance.
  • Focus timer — a Pomodoro-style session timer to structure study blocks and short breaks.
  • Progress dashboard — a clean overview of completed vs. pending tasks to keep momentum visible.
  • Responsive layout — built mobile-first so it works as well on a phone between classes as it does on a laptop.
